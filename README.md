# Dream2Image — ES606 Computational Neuroscience project

Analysis of [Dream2Image](https://huggingface.co/datasets/opsecsystems/Dream2Image) (Bellec, 2025):
EEG recorded before awakening, paired with dream reports. All compute runs on Google Colab; data and
outputs live on Google Drive under `MyDrive/ES606_Dream2Image/`.

## Run order

| Notebook | What it does | Runtime |
|---|---|---|
| `notebooks/00_setup.ipynb` | Hardware check, extras install, gated-access check, version log | any |
| `notebooks/01_data.ipynb` | Download, per-row cache, structural checks, exclusions → `derived/step0.json` | CPU |
| `notebooks/02_preprocess.ipynb` | Epochs E1-E4, filtering, interpolation, artifact rejection → `derived/clean/` | CPU |
| `notebooks/03_features.ipynb` | Band power and specparam aperiodic exponent per epoch × channel → `derived/features_*.csv` | CPU |

To run later notebooks without a new Drive prompt each time, run them from an open notebook's runtime:
`from d2i import runner; runner.run(["02_preprocess.ipynb", "03_features.ipynb"])`.
Executed copies with outputs are saved to `results/notebooks/` on Drive.

Open a notebook in Colab (File → Open notebook → GitHub) or through the Colab extension in VS Code.
Add to Colab Secrets first: `HF_TOKEN` (Hugging Face read token) and, while the repo is private,
`GH_TOKEN` (fine-grained GitHub token, this repo only, Contents read-only).

## Layout

```
config.yaml            every parameter, one place
d2i/                   shared code imported by the notebooks
notebooks/             generated by tools/build_notebooks.py (edit cells there, then rebuild)
results/               tables, figures and logs copied back from Drive for submission
```

Locally, set `D2I_DATA=/some/folder` to point the code at a data folder instead of Drive.

## Data facts established in 01_data

- 129 rows; 122 retained from 37 participants (2 rows have 6 channels, 5 have windows that are not the tail of `eeg_120s`).
- `eeg_120s` is z-scored per channel, and the 15/30/60 s windows are exact copies of its tail: absolute power is not recoverable.
- Two recording sites (title families `case` / `subject`) separate completely above 45 Hz; analyses stay below 30 Hz.
- Cz is dead in every `subject` recording; 16 primary channels.
- The `image` column is never loaded: images were generated from the transcripts and carry no brain information.
